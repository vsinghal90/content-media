# content-media

Public links for **finished, approved** videos, covers and images, so Buffer and Metricool can fetch them when they post.

- One folder per brand: `kaalagni/`, `mathsinshorts/`, `naad-katha/`, `shuddh-desi-bites/` (clothing brands are added when they're onboarded).
- Name files `<what-it-is>_ddmmyy.mp4`, with the cover as `<what-it-is>_ddmmyy-cover.jpg`. Never overwrite a file; add `_v2` and so on instead.
- Link format: `https://raw.githubusercontent.com/vsinghal90/content-media/main/<brand>/<file>`
- **This repo is public.** Never put drafts, client files that aren't approved, or anything private here.

Shuddh Desi Bites (SDB) is a client here like every other brand. The separate SDB content workflow still uses `vsinghal90/sdb-media` for now; this app uses `shuddh-desi-bites/` here.
